# Retained experiment outputs

This ignored tree contains reproducible evidence retained from the numbered
chaos experiments. A directory named `<NNN>` belongs to the experiment with the
same chronological number; its experiment-local README explains the evidence's
status and interpretation.

These files are experimental records, not production assets. Promoted prototype
and operational artifacts belong under
`development/chaos_content/prototypes/<prototype>/outputs/` instead.

The retained data files remain ignored by Git. This README and `.gitignore` are
the only tracked files in this directory. Some experiments intentionally retain
rejected, invalidated, or corrupted fixtures when those artifacts document a
validation boundary. Embedded manifests and summaries remain as originally
generated, so they may record the former output path; current reproduction paths
are documented by the experiment-local READMEs.
