# First-flip logarithmic-consensus demonstration

This is a non-scientific semantic fixture. Its synthetic policy outcomes exist
only to exercise every class in the path

```text
already-computed policy outcomes
    -> consensus classification
    -> dedicated first-flip categorical renderer
```

It does not integrate dynamics and is not field evidence. Run it from the
repository root:

```bash
uv run python -m development.chaos_content.prototypes.state_space_maps.demonstrations.first_flip_logarithmic_consensus.render_fixture
```
