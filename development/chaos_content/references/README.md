# References

This directory is for curated Phase 10 reference notes.

The historic chaos branch README mentioned the following broad references:

- Steven Strogatz, `Nonlinear Dynamics and Chaos`.
- Kathleen T. Alligood, Tim D. Sauer, and James A. Yorke,
  `Chaos: An Introduction to Dynamical Systems`.
- `chaospy` as a possible software reference.
- A Dartmouth double-pendulum numerical-analysis writeup.
- A. M. Calvao and T. J. P. Penna, `The double pendulum: a numerical study`.

These references were not re-reviewed in this task. Future Phase 10 work should
verify exact citations, access, and relevance before relying on them.
