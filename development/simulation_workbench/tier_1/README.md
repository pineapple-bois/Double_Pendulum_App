# Tier 1 Index

Tier 1 defines the evidence and result-contract foundation for future
Simulation page work. It is not a visual redesign tier.

Artifacts:

- `TIER_1_RESULT_CONTRACT.md` sketches the future `SimulationResult` contract.
- `tier1_baseline.py` runs the representative numerical and rendering baseline.
- `tier1_baseline_results.json` stores the compact baseline results generated by the script.
- `TIER_1_NUMERICAL_BASELINE.md` summarizes the Tier 1 numerical evidence.
- `TIER_1B_SOLVER_METADATA.md` records the solver metadata capture follow-up.
- `tier1c_hamiltonian_convention.py` records compact Hamiltonian convention evidence.
- `tier1c_hamiltonian_convention_results.json` stores the compact Tier 1C evidence generated by the script.
- `TIER_1C_HAMILTONIAN_CONVENTION.md` audits the Hamiltonian state convention and recommends the next implementation direction.
- `TIER_1D_OPTION_1_HAMILTONIAN_CONVERSION.md` records the accepted Option 1 implementation.
- `TIER_1_CLOSEOUT.md` closes Tier 1 and states what can move into Tier 2.

File-management rule: keep Tier 1, Tier 1b, Tier 1C, and Tier 1D notes,
scripts, and compact results in this directory. Workbench-wide rules belong one
level up in `development/simulation_workbench/README.md`.
