# Tier 3D Interaction Contract

Tier 3D defines the state and lifecycle contract for a future Simulation
workspace. It builds on Tier 3C.2, where Canvas-native synced inspection became
a stronger production candidate, but it does not promote Canvas or any other
renderer into production.

This tier asks:

- what states can the Simulation workspace occupy?
- which events move the workspace between states?
- when must playback stop?
- how should stale output be represented?
- how should run identity and selected frame behave?
- which parts of the Tier 3C.2 Canvas sync model are candidates for production?

## Files

- `TIER_3D_INTERACTION_CONTRACT.md` - narrative contract and unresolved
  questions.
- `EVENT_MATRIX.md` - event-by-event expected behavior. Start here when
  implementing or reviewing lifecycle logic.
- `interaction_contract_preview.py` - small workbench-only Dash preview that
  simulates the contract states and transitions.
- `tier3d_results.json` - optional compact summary generated by the preview
  script.

## Run The Preview

From the repository root:

```bash
python development/simulation_workbench/tier_3/tier_3d_interaction_contract/interaction_contract_preview.py
```

The preview starts on `http://127.0.0.1:8066/`.

Optional compact results:

```bash
python development/simulation_workbench/tier_3/tier_3d_interaction_contract/interaction_contract_preview.py --results-only
```

## How To Read The Event Matrix

The event matrix records the expected behavior for each event:

- current state;
- next state;
- run ID behavior;
- selected-frame behavior;
- animation-loop behavior;
- payload behavior;
- user-visible message;
- whether Python should be called;
- whether JavaScript should handle it locally.

The central rule is:

> No visual state may continue animating after its simulation result has been
> superseded.

## What This Tier Proves

Tier 3D can prove that the intended interaction contract is explicit,
reviewable, and demonstrable in a small state-machine preview.

It does not prove:

- numerical correctness;
- energy behavior;
- browser memory behavior under long sessions;
- Canvas accessibility/export adequacy;
- final renderer choice.

Those questions remain for Tier 3E or later promotion work.
