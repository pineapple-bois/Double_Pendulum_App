# Simulation Runtime Stability

This folder records durable Simulation runtime stability work. It covers solver
policy, solver/result contracts, callback routing and remount behavior, loading
state, diagnostics, Canvas payload safety, and manual UX inspection.

These documents are tracked summaries distilled from local development
evidence. Detailed workbench directories such as `development/math_fidelity/`,
`development/simulation_workbench/`, and `development/solver_contract/` may
exist locally, but they are ignored and are not required in the tracked repo.
Accepted findings are encoded in production code, tracked tests, and these
durable documentation records.
